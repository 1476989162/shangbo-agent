# 尚搏 Agent 功能说明

本文面向使用者，介绍当前版本（0.7.0）能做什么。开发相关的变更记录见 [CHANGELOG.md](../CHANGELOG.md)。

## 智能模式：直接说人话

输入框上方的工作模式现在有四档：**智能 / 建造者 / 许愿 / 问答**，默认是**智能模式**。

智能模式不额外调用模型，而是按你这一轮的自然语言判断：

- 只是提问、解释、比较 → 按问答处理，只给结论，不乱改文件；
- 有动作 + 工程对象（“把这个报错修一下”“实现导出脚本”）→ 按建造者处理，直接读代码、落盘、验证；
- 明确要交付（“做完”“跑通”“验收”“直到测试通过”“不用问我”）→ 按许愿模式处理，自己改、跑、读错、再修。

判断结果会同时用于提示词、步数预算和工具放行，不会出现“说一套、做一套”。你仍然可以手动切换模式，显式选择优先。

### 少问多做

每轮对话都会生成一份**任务契约**，写清目标、完成判定、决策方式和提问边界。模型默认按最合理的假设继续做，最后在「假设」里集中交代，而不是每一步都回来问你。

只有三种情况会停下来：

1. 不可逆破坏性操作；
2. 对外发送、发布等外部副作用；
3. 缺少必要凭据，或目标对象无法定位。

必须问时要求一次问全，并给出默认选项，不连续追问。

### 执行自治等级

输入框左下角的盾牌按钮可以在三档之间切换，设置会持久保存：

| 等级 | 行为 |
| --- | --- |
| 严格确认 | 所有写入与命令都先问你 |
| 智能自治（默认） | 工作区内读写与安全命令自动放行；工作区外、外部进程、键鼠控制仍需确认 |
| 完全信任 | 常规软风险操作自动放行；硬红线仍然必须人工确认 |

自治等级右侧还有一个独立的**「自动同意」**开关（默认关闭）。打开后，工作区外写入、外部 MCP / CLI、键鼠操作等普通审批会自动同意，不再逐条打断；删 `.git`、删库、格式化磁盘等硬红线仍然会弹窗，开关不能绕过。

### 三条硬红线

以下操作不受自治等级、许愿模式或「始终允许」影响：

1. **磁盘格式化 / 分区 / 擦盘**：永久拒绝，任何模式下都不会执行；
2. **删除 `.git` 仓库、强制推送、硬重置、强制清理、删分支**：必须你本人逐次确认；
3. **删库 / 清表 / 无 `WHERE` 的 `DELETE` / 删除数据库文件**：必须你本人逐次确认。

硬红线确认卡片使用红色样式，并隐藏「始终允许」按钮；许愿模式无人值守时宁可拒绝，也不会默认同意。

## 许愿式编程

下面重点说明四档模式里的**许愿模式**。

切到「许愿模式」后，你只需要写清楚：

1. 想达成什么；
2. 怎样算完成（验收标准）；
3. 在哪个项目目录里做。

Agent 会自己读项目、改文件、跑命令、读报错、继续修，不需要你逐步点确认。任务结束时必须给出改动摘要、实际验证结果、剩余风险和回滚方式。

「设置 → 许愿与自主运行」里可以配置默认验收命令，例如 `npm run typecheck && npm test`。这条命令由主进程真实执行，不经过模型；失败会自动带着错误继续修复。

同一页还可以创建自主任务：

- 手动运行或按固定间隔运行；
- 每个任务设置每日运行次数上限与单轮步数上限；
- 应用常驻托盘后，关闭窗口仍按计划执行；
- 随时全局暂停，不会丢任务定义与历史。

「设置 → 经验进化」保存通过验收的项目经验。后续许愿任务会自动带上这些经验，避免重复踩坑。失败路径不会进入经验库。

**安全边界**：许愿模式自动放行的是当前工作区内的操作。工作区外路径、父目录穿越、密钥库、会话数据库仍会被拒绝；删 `.git`、删库、格式化磁盘会停下来等人工确认，格式化磁盘永久拒绝。

尚搏 Agent 是一个运行在你自己电脑上的个人助手。它能读写本机文件、执行命令、连接外部工具服务，所有数据都留在本地——除了你主动配置的模型供应商，不向任何第三方发送内容。

## 对话

### 基本的提问与追问

在输入框里打字，按 `Enter` 发送，`Shift + Enter` 换行。这是常规用法。

### 编辑与重新生成

- **编辑**：点自己某条消息下方的「编辑」，修改后重新发送。这会生成一个新分支，原始版本仍然保留。
- **重新生成**：点 AI 回复下方的「重新生成」，让模型对同一条问题重新回答。多次重新生成会产生多个分支，可以用 `‹ 1/3 ›` 在分支间切换。

### 历史导航

窗口左上角的 `‹` `›` 可以在访问过的会话之间前后跳转，就像浏览器的后退/前进。回到更早的会话后发送新消息，会自动从那个位置分出新的一条线，不会影响后面的内容。

## 发图片给模型

模型可以看图。两种方式：

1. **粘贴**：在输入框按 `Ctrl+V`，剪贴板里的截图会变成待发图片
2. **拖拽**：把图片文件直接拖进输入框

支持的格式：PNG、JPEG、WebP、GIF、BMP，单张不超过 6MB，一次最多 8 张。

**发送前**：待发图片显示在输入框上方的缩略图条里。点缩略图可以放大看，点右上角 `×` 移除某一张。图片不是必须配文字——只发图也可以，模型会直接看你贴的图。

**发送后**：图片留在对话气泡里，随时点开查看大图。

> 图片保存在你电脑的本地数据目录中，数据库里只记一条路径。因此读取历史会话时不会因为图多而变慢。删除会话时，对应的图片会一并删除。

## 等待回复时继续提问

AI 正在回复时，输入框**依然可以正常使用**。你可以先把下一个问题写好，按 `Enter` 发送，它会排在当前回复之后自动执行。

- 排队中的消息在对话流里显示为**待处理**，界面上告诉你还要排几个
- 输入框上方会显示「正在生成中，可继续录入下一条」
- 发送按钮变成排队图标，点它和按 `Enter` 效果相同
- 顶部的**停止**按钮只中断当前这一轮，排队的消息会继续依次执行

这个设计让你可以把一个复杂任务拆成几步连续下达，而不必等每一步跑完再输入下一步。

## 多个任务同时进行

**每个会话独立运行。** 你可以让 A 会话在跑长任务时，切到 B 会话问别的事，两者互不干扰。

- 正在运行的会话在左侧列表里有**呼吸灯**标记
- 切走再切回，运行状态不会丢失，仍显示「正在生成中」
- 只有**同一个会话内**的任务会排队；不同会话之间真正并行

## 工具与能力

### 文件与命令

模型可以读写你指定的工程目录、执行终端命令。

- **首次使用需授权**：涉及修改的操作（写文件、执行命令）会弹出确认框，说明要做什么、参数是什么。你可以点「始终允许」把某个工具加入永久放行列表（在设置里能一键清空）
- **默认模式**：输入框左下角显示当前是「安全确认模式」还是「直接放行模式」，点它可以切换
- 工具执行时能看到实时状态——正在读哪个文件、执行什么命令，而不是笼统的「处理中」

### MCP 外部服务

MCP 是一套标准接口，让模型使用外部工具服务。在「设置 → MCP」里能看到每个服务的实时状态：是否启用、进程是否活着、有哪些可用工具。点刷新按钮可重新探测。

### 桌面操作

开启后，模型可以查看屏幕截图、点击、输入文字、按键、滚动，用于操作没有命令行接口的图形程序。

> 开启前请留意：模型能操作你屏幕上的一切，包括其他程序的窗口。

### 子任务

遇到复杂任务，模型可以派生子任务并行处理，完成后汇总结果。这对多文件改造这类工作比较有帮助。

### 思考强度

输入框右侧可调「思考强度」，从「极速」到「极限」五档：

| 档位 | 适用场景 |
| --- | --- |
| 极速 | 简单查询，模型能直接答的 |
| 快速 | 常规对话，响应敏捷 |
| 标准 | 多数任务，推荐默认 |
| 高 | 需要仔细推导的任务 |
| 极限 | 复杂算法、架构设计 |

调高会消耗更多时间和配额，但答案质量更稳。**如果发现回复写到一半断了，多半是思考占满了输出配额**——此时可以点「智能继续生成」，或把强度调低一档。

## 界面

### 协同 / 代码双视图

顶部可切换「协同」和「代码」两种视图。

### 上下文用量

点输入框上的徽标（如 `1M`）可查看上下文窗口的占用明细——工具定义、系统提示、历史消息各占多少，以及还剩多少空间。这些数值是实测的，不是估算。

### 导出

右上角「导出」按钮把当前会话分支导出为 Markdown 文件。

### 工程目录绑定

输入框上方的目录标签可以绑定本机工程目录。绑定后模型的相对路径操作以它为基准，`run_command` 也默认在那里执行。

## 数据与隐私

| 内容 | 存放位置 |
| --- | --- |
| API Key | 经系统密钥环（Windows 为 DPAPI）加密，不落明文 |
| 会话记录 | 本地 SQLite 数据库 |
| 粘贴的图片 | 本地数据目录的 `images` 文件夹 |
| 运行日志 | 本地数据目录的 `logs` 文件夹 |

Windows 下数据目录通常是 `%APPDATA%\shangbo-agent`，确切路径在「设置 → 通用 → 系统信息」里能看到。

**没有遥测。** 发给模型的内容就是对话上下文本身，不含任何额外数据。

## 更新

应用会自己检查新版本：启动 20 秒后查一次，之后每 24 小时一次，检查的是本项目的 GitHub Releases。

- 发现新版本后默认在后台下载安装包，期间不影响你使用；下载完成会发一条系统通知。
- **安装永远需要你确认**：设置页出现「重启安装」按钮，或退出时自动完成安装。应用不会自己重启打断你。
- 想手动触发：托盘菜单「检查更新…」，或「设置 → 常规设置 → 应用更新」里的「检查更新」。
- 不想要自动检查：在同一处关掉「自动检查更新」开关，之后仍可手动检查。

**从 0.2.1 或更早版本升级**：那些版本里没有更新代码，不会自动升级。需要到 Releases 页面下载新安装包，手动安装一次；安装不会动你的会话、图片和密钥（它们保存在数据目录，与安装位置无关）。装上 0.2.2 之后就再也不用管了。

## 常见问题

**发图后模型说看不到图？**
检查所选模型是否支持视觉输入。纯文本模型无法读取图片。

**排队消息一直不执行？**
确认会话没有被删除。若点击了「停止」，只会中断当前这一轮，队列会继续。删除会话则会连带清掉它的排队项。

**回复被截断了？**
点消息下方的「智能继续生成」，或把思考强度调低后重试。

**想重新开始某段对话？**
编辑那条用户消息重新发送即可，原分支会保留。
