# 尚搏 Agent · 评委体验入口说明（TRAE 好应用大赏赛）

> 结论：桌面客户端（Windows x64）+ AI 智能体，无需本应用账号、无邀请码、无付费。请从 GitHub Releases 公开下载安装包，全程约 5 分钟可进核心功能。

## 1. 入口（公开可访问，接受核验）

- **下载页（首选）：https://github.com/1476989162/shangbo-agent/releases/latest**
- 安装包文件名示例：`shangbo-agent-setup-0.9.4.exe`（随版本递增，认 `latest` 页最新版即可）
- 同页另有 `latest.yml` + `.blockmap` 为自动更新元数据，无需手动下载。
- ⚠️ 不提供百度网盘 / 夸克网盘链接，全部走 GitHub 公开 Release。

若评审环境打不开 GitHub，请联系作者提供直链安装包（HTTP/HTTPS），不走网盘。

## 2. 运行环境

- OS：Windows 10 / 11，64 位（x64）。Mac / Web / 小程序均无产物，请勿在其他端查找。
- 硬件：任意能跑 Electron 的 PC 即可，建议 8G+ 内存，磁盘留 1GB（含数据目录）。
- 依赖：安装包为免开发环境包，**无需安装 Node.js / Python**。Python 边车与 C-Core 已打进包内。
- 权限：按用户级安装（NSIS，`perMachine=false`），无需管理员权限，可改安装目录。
- 数据位置：`%APPDATA%\shangbo-agent`（会话 SQLite + 图片 + 日志）。确切路径可在「设置 → 通用 → 系统信息」查看。

## 3. 账号 / 费用 / 网络说明（按赛制要求明示）

- **本应用无登录、无注册、无邀请码、无付费点。** 打开即用。
- **需要自备一个模型 Key（必须明示）：** 本应用不内置任何 Key，首次启动需配一个供应商才能对话。这是唯一门槛，非本应用收费。
  - 有 Key：DeepSeek / 通义千问 / 智谱 GLM / Claude 任选其一即可，详见第 4 节。
  - 无 Key 零成本方案：本地 Ollama，`Base URL=http://localhost:11434/v1`，API Key 随便填非空（如 `ollama`），拉取 `qwen2.5:7b` 等模型即可离线体验问答与文件改写。
- **网络：** 需能访问 GitHub（下载）+ 你所选模型供应商。无特定内网要求，不翻墙可用国内供应商（通义 / 智谱 / DeepSeek）。

## 4. 打开后进入核心功能的步骤（3 步必走）

### 步骤 A：安装并启动（1 分钟）
1. 打开上方 Releases 页 → 下载 `shangbo-agent-setup-*.exe` → 双击安装 → 桌面/开始菜单打开「尚搏 Agent」。
2. 首次进入为欢迎页，可看到「懂你说什么 / 少问多做 / 红线不越」能力卡。

### 步骤 B：配置模型（2 分钟，只做一次）
1. 左下角点「设置」→「模型供应商」。
2. 预置模板有 DeepSeek / 通义千问 / 智谱 GLM / Claude / Ollama，默认均为停用。
3. 选一个点「编辑」→ 填入 **API Key** → 点「拉取模型列表」（或手动逐行填模型名，如 `deepseek-chat`）。
   - OpenAI 兼容协议必须带版本前缀：如 `https://api.deepseek.com/v1`；Anthropic 填 `https://api.anthropic.com`（不带 `/v1`）。
4. 勾上「启用该供应商」并保存。回到对话页，输入框左下角会出现供应商与模型下拉。
5. 多供应商可设不同优先级（数值越小越先用），网络错误/429/5xx 自动降级；401/400 配置错误会直接报错，不静默切换。

### 步骤 C：体验 3 个核心点（3 分钟）
1. **智能问答：** 输入框顶部确认是「智能模式」，直接问「解释下闭包」，只答不改文件。
2. **建造者改文件：** 先绑定一个测试工程目录（输入区上方目录标签），然后说「给这个目录加一个 `hello.py` 并跑通」。观察：自动读码 → 落盘（优先补丁）→ 跑命令 → 贴真实输出。
3. **许愿交付 + 安全红线：** 切到「许愿模式」，说「目标：xxx；验收：`npm test` 通过」。无人值守自动修；再试一句高危如「格式化 D 盘」或「删 .git」，应被永久拒绝/弹窗确认，验证红线焊死。

## 6. 常见问题

- 发图模型说看不到：换有视觉能力的模型，纯文本模型不支持看图。
- 回复写一半断了：点「智能继续生成」，或把思考强度调低一档。
- 旧版 0.2.1 及更早无自更新：手动装一次新包即可，此后自动更新。
